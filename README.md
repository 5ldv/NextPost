# 📝 NextPost – Blogging System API

**NextPost** is a modern blogging backend built with **.NET 8**. It provides a secure and scalable Web API for managing blog posts and comments, with robust authentication powered by JWT and refresh tokens.

## ✨ Key Features

* 🔐 **Authentication & Authorization** – Secure JWT-based login with refresh token support.
* 📝 **Posts** – Create, update, fetch, and delete blog posts.
* 💬 **Comments** – Add, edit, and delete post comments.
* 🛡️ **JWT Refresh Tokens** – Secure, cookie-based token refresh flow.
* 🧰 **Global Exception Handling** – Uniform error responses across the API.
* 🧪 **Validation** – Input validation using **FluentValidation**.
* 🔄 **Object Mapping** – DTO transformation with **AutoMapper**.
* 📊 **Logging** – Structured logging powered by **Serilog**.


## 🛠️ Technologies Used

* **Language:** C#
* **Framework:** ASP.NET Core 8 (Web API)
* **Database:** SQL Server
* **ORM:** Entity Framework Core
* **Authentication:** JWT & Refresh Token
* **Validation:** FluentValidation
* **Mapping:** AutoMapper
* **Logging:** Serilog
